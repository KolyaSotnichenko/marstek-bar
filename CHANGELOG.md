# Changelog

## 1.0.0 (2026-10-28)

First public release.

- Large desktop widget: charge ring, power flow (grid, battery, home, socket),
  forecast, temperature, today's energy, 24-hour chart.
- Menu bar item with live charge and a dashboard panel.
- Automatic discovery, rediscovery when the battery's IP changes.
- Ukrainian and English interface.
- Read-only access to the Marstek local API (UDP, port 30000).
